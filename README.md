## GitHub Pages
1. Upload toàn bộ file/thư mục lên repository.
2. Settings → Pages → Deploy from branch → chọn `main` + `/root`.
3. Mở URL Pages.

Dữ liệu học tập nằm trong LocalStorage của trình duyệt. Muốn chuyển máy: Trang chủ → Xuất bản sao lưu → máy mới → Khôi phục từ file.
