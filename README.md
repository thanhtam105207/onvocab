# ENT303 - Top Notch 3 Master Hub

PWA học tiếng Anh dựa trên file HTML gốc.

## Chạy bằng GitHub Pages

1. Tạo một repository trên GitHub.
2. Upload toàn bộ các file/thư mục trong project này, giữ nguyên cấu trúc:
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icons/icon-192.png`
   - `icons/icon-512.png`
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Mở URL GitHub Pages được cấp.

## Cài như ứng dụng

- Chrome/Edge trên máy tính hoặc Android: mở trang HTTPS → chọn **Cài app / Install app**.
- iPhone/iPad: Safari → **Chia sẻ → Thêm vào Màn hình chính**.

Lưu ý: dữ liệu học do ứng dụng hiện tại lưu bằng LocalStorage nên chủ yếu nằm trên từng trình duyệt/thiết bị.
